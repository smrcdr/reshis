# Решись Авиа — frontend

React/TypeScript: форма рейса, прогноз, график квантилей и авторизация.
Полная инструкция по запуску и проверкам: [../README.md](../README.md).

`npm run dev` — Vite на порту 5173; `npm run build` — сборка для раздачи backend.
`npm test` — регрессионная проверка состояния формы; `npm run lint` — ESLint.
`npm run api:types` обновляет типы из `../openapi.yaml`.
