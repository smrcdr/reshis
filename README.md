# Решись Авиа

Приложение варианта C: React/TypeScript отправляет параметры рейса в NestJS API. Backend читает собственный ML-прогноз из CSV, рассчитывает спрос и продажи. PostgreSQL хранит пользователей, пароли защищены bcrypt, доступ к прогнозу — JWT.

Реализованы выбор маршрута, даты и цены, прогноз продаж, девять квантилей, график распределения, регистрация и вход. Данные содержат пять маршрутов из Москвы, 155 рейсов с 1 июня по 1 июля 2026.

## Локальный запуск

Нужны Node.js 24, npm и Docker Compose.

```sh
cd backend
cp .env.example .env
npm ci
npm run db:up
npm run db:deploy
cd ../frontend
npm ci
npm run build
cd ../backend
npm run build
npm run start:prod
```

Страница: http://localhost:3000, Swagger: http://localhost:3000/api/docs.
Для разработки запустите `npm run start:dev` в backend и `npm run dev` в frontend. Vite работает на http://localhost:5173 и проксирует API на порт 3000.

## Проверки

В backend: `npm test -- --runInBand`, `npm run test:e2e -- --runInBand`, `npm run lint`. E2E используют локальную БД из `.env`, создают уникальных тестовых пользователей и удаляют их после проверки.
В frontend: `npm test`, `npm run lint`, `npm run build`. Компонентный регрессионный тест проверяет очистку цены во время задержки и получения ответа.

## Особенности расчёта

Спрос = медианный базовый спрос − чувствительность × (цена − базовая цена). По выбранному правилу спрос округляется до десятых, продажи ограничиваются числом мест и нулём, затем округляются вниз до целого. Это правило округления сохранено по решению автора.
Высота столбцов графика отражает плотность вероятности, каждый интервал между соседними квантилями имеет вероятность 10%. Значения вне крайних квантилей составляют два хвоста по 10%.
Пароли ограничены 72 байтами UTF-8 и проверяются на клиенте и сервере. Пустые числовые ячейки CSV считаются ошибкой.

## Production

Адрес: https://reshis.modelport.org. Развёртывание — отдельный Docker Compose проект на modelport-prod с собственной базой и постоянным томом. Порт 38100 опубликован только на loopback, HTTPS обслуживает Caddy.
Создайте `.env.production` (не включать в архив/репозиторий):

```dotenv
POSTGRES_USER=reshis
POSTGRES_DB=reshis
POSTGRES_PASSWORD=<случайный-пароль>
DATABASE_URL=postgresql://reshis:<тот-же-пароль>@postgres:5432/reshis
JWT_SECRET=<случайный-секрет>
NODE_ENV=production
```

```sh
docker compose -f compose.prod.yaml up -d --build --wait
```

Миграции применяются при запуске приложения. Повторная сборка не удаляет пользователей. Не выполняйте `down -v`, если нужно сохранить базу.

## ИИ и инструменты

Для проверки и доработки использован OpenAI Codex (семейство GPT-6): анализ требований и кода, исправления, регрессионные тесты и подготовка развёртывания. ML-прогноз подготовлен с AutoGluon. Инструмент первоначальной генерации проекта по файлам достоверно не установлен.

Для сдачи предоставьте код в ZIP с ФИО или открытый репозиторий и ссылку на приложение. Не включайте `.env`, ключи, node_modules и данные базы.
